# NFD SDK Examples

This directory contains example applications demonstrating how to use the NFD SDK.

## Available Examples

- [**resolve**](./resolve): Demonstrates how to use the `resolve` method to look up NFD data directly from the blockchain.
- [**mint**](./mint): Shows how to use the `getMintQuote` and `mint` methods to mint new NFDs on TestNet.

## Running the Examples

Each example is a standalone application with its own README and instructions. To run an example:

1. Navigate to the example directory
2. Install dependencies with `pnpm install`
3. Start the development server with `pnpm dev`
4. Open your browser to the URL shown in the terminal (usually `http://localhost:5173`)
